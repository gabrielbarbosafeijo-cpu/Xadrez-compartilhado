# Créditos das peças

As 12 imagens SVG desta pasta são o conjunto **cburnett**, criado por
[Colin M. L. Burnett](https://en.wikipedia.org/wiki/User:Cburnett) e distribuído pelo
projeto [Lichess](https://github.com/lichess-org/lila/tree/master/public/piece/cburnett).

- **Licença:** [GPLv2+](https://www.gnu.org/licenses/gpl-2.0.txt), conforme o arquivo
  [COPYING.md](https://github.com/lichess-org/lila/blob/master/COPYING.md) do repositório do Lichess.
- **Arquivos:** `wK`, `wQ`, `wR`, `wB`, `wN`, `wP` (brancas) e `bK`, `bQ`, `bR`, `bB`, `bN`, `bP` (pretas).
  O nome de cada arquivo é o código da peça usado no programa (cor + tipo).
- Os arquivos não foram modificados.
